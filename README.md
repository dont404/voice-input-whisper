# Голосовой ввод 2.2 — Whisper

Офлайн-диктовка на русском языке для Windows. Удерживаете клавишу, говорите, отпускаете — текст вставляется туда, где находится курсор.

Используется только faster-whisper с моделью `large-v3-turbo`. После установки интернет и VPN для распознавания не нужны.

## Установка одной командой

Откройте **PowerShell** и выполните одну строку:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/dont404/voice-input-whisper/main/web-install.ps1 | iex"
```

Команда сама:
- скачивает и проверяет ZIP-архив;
- распаковывает программу в `%LOCALAPPDATA%\VoiceInput`;
- при отсутствии устанавливает Python 3.12;
- устанавливает необходимые библиотеки;
- создаёт ярлык на рабочем столе и в автозагрузке;
- запускает голосовой ввод.

Во время установки нужны интернет и примерно 4 ГБ свободного места. Если загрузка оборвалась, выполните ту же команду ещё раз.

## Установка из ZIP вручную

1. Откройте [последний Release](https://github.com/dont404/voice-input-whisper/releases/latest).
2. Скачайте `GolosovoyVvod.zip`.
3. Распакуйте архив и запустите `install.bat`.

Модель уже находится в ZIP, поэтому отдельно скачивать её не нужно.

## Использование

- **Удерживать F9** — говорить; отпустить — распознать и вставить текст.
- **F10** — следующая вставка без начального пробела.
- **Правый клик по значку у часов → «Переназначить клавиши»** — выбрать свои клавиши.
- **Ctrl+Alt+Q** — выход.

При переназначении окно покажет обе выбранные клавиши. Нажмите «Подтвердить» для сохранения или «Отмена», чтобы ничего не менять.

## Совместимость

- Windows 10/11;
- Python 3.12;
- faster-whisper 1.2.1;
- PyAV 18.x (`av<19`);
- NVIDIA CUDA при наличии поддерживаемой видеокарты, иначе используется процессор.

Программа работает локально и не отправляет речь на серверы.
